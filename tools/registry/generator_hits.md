Each row is a line that mentions a registry address (as `0x0047496b`, `0047496b` or inside a name such as `FUN_0047496b`) together with a quoted name that is not the verified one. Ghidra default names for the same address (`FUN_`, `DAT_`, ...) are ignored: they are the lookup key of a rename, not its result, and so are bare lower-case words such as dictionary keys. A line can still be harmless (a comment, an address list, the old side of a rename pair); read it before acting. Every program loads at `0x00400000`, so a `DUEL.EXE` script can name a different function at a `MAGIC.EXE` registry address; such rows are marked.
