# Duplicate function names

Generated by `audit_names.py`; do not edit by hand.

A function name carried by more than one address in the same program's `function_index.csv`. Renaming by name (sed, a rename map keyed by the old name, a Ghidra script looking the name up) hits every address in the group, which is how the `Glue_Subsystem_004cdb4f` rename landed on two different `DUEL.EXE` functions. Rename these by address.

**Registry** marks a group that involves a verified name (`name`: the shared name is a registry name, in either program) or a verified address (`address`: one of the addresses has a registry row in this program). `in the doc, not registered` flags an address `SYMBOL_VERIFICATION.md` writes down without a registry row (the doc does not say which program each prose address is in, so check the line).
